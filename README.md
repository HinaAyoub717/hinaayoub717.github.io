# Hina Ayoub | Portfolio Website

My personal portfolio website, built with HTML, CSS and JavaScript. It showcases my skills, projects and ways to contact me.

Live site: https://hinaayoub717.github.io/

## Features
- Responsive layout that adapts to phones, tablets and desktops
- Navigation menu with clear sections (Home, About, Skills, Projects, Contact) that turns into a hamburger menu on small screens
- Animations and transitions: scroll reveal effects, hover effects and a scrolling technology strip
- Project cards with interactive demos and links to the code
- Contact section with a form that opens the visitor's email app
- Custom favicon

## Built with
HTML, CSS and JavaScript (no libraries)

## What I practiced
- Responsive design with CSS
- Animations and transitions
- Building a user-friendly, responsive navigation menu
- Organising a website into clear sections

## How to run
Open `index.html` in your browser.
